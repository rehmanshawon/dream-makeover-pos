# Dream Makeover POS

Offline-first luxury beauty salon POS and business management system.

## Architecture

This is an npm workspaces monorepo.

| Package | Purpose |
|---|---|
| `backend` | NestJS API and business logic |
| `frontend` | React POS interface |
| `desktop` | Electron desktop shell |

## Prerequisites

- Node.js 20+
- npm 10+
- MySQL 8.x

## Development Setup

```bash
npm install
```

## Scripts
```bash
npm run lint
npm run format
npm run type-check
npm run test
npm run build
```
